KENSEITUNE — FINAL PUBLISH BUILD
================================

This is the final YouTube-only KenseiTune web app, configured as an installable
Progressive Web App (PWA). It has one search bar, one Google sign-in flow,
YouTube search/playback, and automatic LRCLIB lyrics when a match is available.

PUBLISH TO YOUR EXISTING GITHUB PAGES SITE
------------------------------------------
1. Download and extract this ZIP.
2. Open your GitHub repository: jomarjohn00-collab/Kensei-Tune
3. Upload/replace the CONTENTS of this folder in the repository root.
   Keep the folders and files in their existing structure (especially /icons).
4. Commit the changes to the main branch.
5. Open the GitHub Pages URL after deployment finishes:
   https://jomarjohn00-collab.github.io/Kensei-Tune/

GOOGLE SIGN-IN + YOUTUBE SETUP (REQUIRED FOR GOOGLE LOGIN)
---------------------------------------------------------
1. Go to https://console.cloud.google.com/ and create/select a project.
2. Enable YouTube Data API v3.
3. Configure Google Auth Platform / OAuth consent screen. If the app is in
   Testing mode, add your Google account as a test user.
4. Create an OAuth Client ID; choose Web application.
5. Add this Authorized JavaScript origin exactly:
   https://jomarjohn00-collab.github.io
6. In KenseiTune open Settings > Account. Paste the OAuth Client ID and save.
7. Tap Sign in with Google and approve the requested YouTube read-only access.

You can also add a YouTube Data API v3 API key in Settings > Account as a
search fallback. Restrict the key to the GitHub Pages website referrer and
YouTube Data API v3. Never put an OAuth client secret in this website.

INSTALL AS AN APP
-----------------
After GitHub Pages is live, open the site in Chrome on Android. Open the
browser menu (three dots) and choose Install app or Add to Home screen.
On supported browsers, KenseiTune opens in its own app-style window.

IMPORTANT SERVICE LIMITATIONS
-----------------------------
- One Google sign-in authorizes supported YouTube Data API access; it does
  not create a private YouTube Music streaming API or unlock unrestricted
  YouTube Music Premium playback.
- Search uses YouTube Data API v3. Playback uses YouTube's official embedded
  player and remains subject to YouTube controls, ads, region restrictions,
  age restrictions, and embed availability.
- This is not the official YouTube Music app and cannot reproduce all of its
  subscription-only or background-playback features.
- Lyrics are looked up from LRCLIB when an accurate match is available.
- Google OAuth Client ID and API key must be created in your own Google Cloud
  project. They cannot be generated by this static app.
- Google credentials/tokens are handled in the browser; use a personal device.
